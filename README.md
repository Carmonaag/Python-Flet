📝 noteX

Aplicativo de anotações moderno desenvolvido com Flet e Python.
O noteX é um app multiplataforma para criação, organização e gerenciamento de notas de forma simples, rápida e intuitiva — com interface moderna, persistência local e sincronização futura via nuvem.

🚀 Recursos Principais

✍️ Criação e edição de notas com título e conteúdo em tempo real

🗂️ Organização por categorias ou tags personalizadas

🔍 Busca instantânea entre notas existentes

💾 Persistência local automática (usando SQLite ou JSON)

🌙 Modo claro e escuro

📱 Interface responsiva, compatível com desktop e PWA (Progressive Web App)

☁️ Pronto para integração com banco de dados remoto (Firebase / Supabase)

🧰 Tecnologias Utilizadas
Tecnologia	Descrição
Python 3.10+	Linguagem principal do projeto
Flet	Framework para criação de apps web e desktop com Python
SQLite / JSON	Armazenamento local das notas
Flet Routing & Controls	Navegação e componentes da interface
